# Security & Compliance

## Overview

The PostgreSQL Blockchain Extension provides:

- **Immutability**: Data cannot be modified after insertion
- **Cryptographic Integrity**: SHA-256 hash chaining
- **Tamper Detection**: Chain verification
- **Audit Compliance**: Complete provenance trail
